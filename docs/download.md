# 下载 Mac 客户端

Media Marshal 把夸克文件下载到本机，或整理已有的本地文件，再按确认结果复制到媒体库并核对已有 Emby 的收录。

**此页尚未开放安装包下载。** 当前留档产物用于内部验收，尚未完成正式签名、公证及完整发行验收。可先查看下方架构与使用条件，以及[0.2.1 内测归档说明](./releases/0.2.1-preview.md)。

## 选择架构

在 Mac 的「关于本机」查看芯片或处理器信息。

| 你的 Mac | 对应架构 | 当前状态 |
| --- | --- | --- |
| Apple Silicon（M 系列芯片） | arm64 | 已有内部目录包及 DMG 安装验证；尚未开放下载 |
| Intel 处理器 | x64 | 同一客户端的运行与安装验收尚未完成；暂无下载 |

当前实际验证环境为 **macOS 26.5.2／Apple Silicon**。最低支持的 macOS 版本尚未验收，不能把 Electron 的系统要求或构建配置当作本产品已验证的范围。Windows 等其他客户端由后续变更承接。

## 开始前需要什么

下载、文件整理和 Emby 收录是三个阶段，可以按需要配置。

| 使用方式 | 需要准备 | 文件去向 |
| --- | --- | --- |
| 在应用内下载夸克文件 | 本人的可用夸克账号、网络连接、独立本地下载目录与足够空间 | 文件下载到本地；只下载无需 TMDB 或 Emby |
| 整理夸克官方客户端已下载的文件 | 用户先确认下载完成，选择本地输入目录；另选媒体库目标，并准备 TMDB Key | 识别并核对 COPY 预览，确认后复制；输入文件保留 |
| 整理普通本地目录 | 已有本地文件、独立媒体库目标、TMDB Key | 观察文件状态，识别并人工确认后复制 |
| 整理完成后在 Emby 中收录 | 已有可用 Emby 服务器、本人可用的连接密钥及媒体库目录映射 | 复制完成后刷新并核对收录；本客户端不安装或重置 Emby |

应用内夸克下载所需的 OpenList、Rclone 和守护组件随包提供，无需另装这些工具或夸克客户端。选择「夸克客户端本地目录」时，下载由官方客户端完成；普通目录接入不代表支持其他网盘的账号连接或下载行为。

下载／输入目录和媒体库目标需要分开，COPY 会额外占用存储空间。密钥只在客户端「设置」中填写，目录通过系统选择器授权。详细步骤见[来源、下载与整理](./product/cloud-downloads.md)和[客户端设置](./product/desktop-settings.md)。

## 安装、升级与数据保留

开放某个架构的下载时，将在此页提供该产物的版本、适用系统、签名状态、发行说明与 SHA-256；只为通过对应验收的产物提供入口。

首版采用手动整包升级。在旧客户端选择「准备升级并退出」，等待停写与备份完成，再替换整个 App。恢复旧版本时使用匹配的备份；恢复业务数据不会撤销已经复制的媒体文件。卸载 App 与删除媒体、配置和备份是不同操作，媒体来源和目标应保留。参见[升级与恢复说明](./product/cloud-downloads.md#手动整包升级和恢复)。

当前内部安装验证记录见[Mac 安装态验证](./architecture/mac-installation-validation.md)。这份记录的具体构建与下方归档对应；后续源码和其他架构的验收分别记录。
