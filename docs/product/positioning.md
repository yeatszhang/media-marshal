# Media Marshal 产品定位与运营方向

更新日期：2026-10-17。本文用于产品规划和内容运营；桌面安装、一站式配置和引导流程属于规划，当前可用能力以[用户手册](../user-guide.md)为准。

## 核心定位

**用现有电脑和一块移动硬盘，低成本搭建自己的家庭影院。**

用户想要的是把喜欢的电影、剧集收进自己的媒体库，在电视、手机和平板上方便地观看。先帮助用户完成这件事，再根据实际需要升级设备。NAS 不是入门前提，Apple TV 也是可选的体验升级。

Media Marshal 负责把下载后的文件持续整理成可用的媒体库，并通过教程和产品引导，帮助用户接好存储、媒体服务和播放器。对外从“怎样拥有自己的家庭影院”讲起，让用户在使用过程中理解自动整理的价值。

商业方向是免费提供便捷、完整的整理工具，官方识别与整理 API 按需付费，后续通过托管消息通知等服务扩展会员价值。具体免费边界、三个推进阶段、价格实验与转化指标见[商业模式、内容运营与付费策略](./business-and-operations.md)；付费服务和候选价格均不代表已经上线。

## 核心用户与场景

优先服务中国市场中已有电脑、会用网盘客户端下载文件，但不熟悉媒体库搭建的家庭影音用户。

| 场景 | 用户遇到的问题 | 希望交付的结果 |
| --- | --- | --- |
| 第一次搭建 | 以为必须先买 NAS，不知道从哪里开始 | 用现有设备播出第一部影片 |
| 持续收片和追剧 | 下载目录混乱，改名、分季、搬运都要手动处理 | 下载完成后持续整理，拿不准的识别由用户确认 |
| 客厅观影 | 文件在电脑上，家人不会找，也不方便在电视上播放 | 打开播放器，浏览海报和剧集后直接观看 |
| Apple TV 升级 | 不清楚设备怎么选、App 怎么装、Infuse 怎么买 | 按教程完成安装、购买和媒体库连接 |

第一阶段聚焦家庭局域网内的电影和普通剧集。用户成功的标志是“在常用设备上稳定看完一部影片，并且下次新增文件仍能顺利入库”。

## 国际化与中国用户优先

**从设计之初支持国际化，产品体验与交付优先服务中国用户。**

简体中文作为默认体验，保留英文入口，语言资源与业务逻辑分离，后续可扩展更多语言。新功能同步考虑界面、引导、错误提示和通知的多语言表达；日期、时间、数字等按用户语言、地区和时区展示。

优先打磨中文片名、别名与中文文件名识别，以及中国用户常用网盘客户端、本地存储和播放器的接入教程。安装下载、更新、元数据与后续内置 API 的选型和验收，优先验证中国大陆网络环境中的可用性。

界面语言、元数据语言、地区与时区分别配置；语言切换保持已有作品身份和整理结果稳定，已有文件的重命名通过显式整理或修正操作执行。中国市场的默认配置与服务入口应可扩展到其他地区。详细需求与验收见 REQ-16。

## 低成本方案

### 基础组合

| 组成 | 作用 | 入门选择 |
| --- | --- | --- |
| 电脑 | 运行整理工具和媒体服务 | 优先复用现有 Windows 或 Mac 电脑 |
| 存储 | 保存下载文件和整理后的媒体库 | 现有硬盘或移动硬盘，空间不足再扩容 |
| Emby Server | 管理媒体库，向播放设备提供访问 | 安装在电脑上，添加硬盘中的电影和剧集目录 |
| 播放器 | 浏览媒体库和播放视频 | 先引导网易爆米花；有需要再选择 Infuse |
| Media Marshal | 持续识别、整理、修正媒体文件 | 从人工整理过渡到自动整理 |
| 电视播放设备 | 在客厅观看 | 先使用已有且支持所选播放器的设备，按需增加 Apple TV |

Emby Server 可以运行在 Windows 和 Mac 电脑上，家庭媒体库不依赖 NAS。[Emby 官方入门说明](https://emby.media/support/articles/Quick-Start.html)

观看时，保存文件的电脑需要开机，Emby 服务需要运行，移动硬盘需要保持连接。教程应覆盖电脑休眠、硬盘断连和局域网连接问题；有全天候访问需求时，再介绍常开主机或 NAS。

### 按需求投入

- **先验证体验：**复用电脑、硬盘和现有播放设备，用网易爆米花连接媒体库。官方应用说明列有 Emby 接入能力。[网易爆米花官方应用介绍](https://apps.apple.com/cn/app/网易爆米花-智能媒体库-全能云盘网盘播放器/id6480252695)
- **升级播放器：**向 Apple 设备用户介绍 Infuse，演示连接和播放流程，再根据实际需求引导购买 Pro。官方提供月订阅、年订阅和终身购买选项，具体费用以用户所在地区的购买页面为准。[Infuse 官方购买说明](https://support.firecore.com/hc/en-us/articles/360046954753-Purchases-and-Family-Sharing)
- **升级客厅体验：**需要独立电视播放设备时，再增加 Apple TV，并提供从连接电视到播放媒体库的完整教程。

“低成本”指优先复用设备、减少首次投入。对外介绍费用时，分别列出硬件、播放器购买或订阅、按需使用的 Emby 付费功能，以及存储和用电成本。已有设备足够的用户可以降低新增支出；需要购买硬盘或 Apple TV 的用户应看到相应预算。

## 从准备文件到电视播放

主推路径：获取视频文件 → 下载到电脑 → MM 整理到硬盘媒体库 → Emby 收录 → 网易爆米花或 Infuse 播放。

### 第一步准备设备和一部示例影片

先让用户确认电脑系统、硬盘位置和播放设备，再提供对应教程。第一轮用一部文件结构简单的示例影片完成验证，不要求先整理全部收藏。

教学中明确区分下载目录和媒体库目录。跨电脑硬盘与移动硬盘整理时，要考虑复制所需的额外空间；桌面方案计划默认复制、保留来源文件，不能把复制描述成零空间成本。

### 第二步建立媒体库

安装 Emby Server，分别添加电影和剧集目录，确认电脑端能看到影片和海报。初次使用可以先手动放入示例文件；用户开始持续下载后，再接入 MM 的目录监听、识别和整理。

MM 的价值在于省掉重复操作：按统一结构整理、处理季集信息、确认不确定的匹配，以及修正错误识别。只有少量文件、手动整理已经够用的用户，可以先完成播放体验。

### 第三步连接网易爆米花或 Infuse

面向用户使用“连接你的 Emby 媒体库”这一说法。引导用户找到服务器地址和端口，使用自己的 Emby 播放账号登录，并确认播放设备和电脑处于可互通的家庭网络。

教程需要展示“这些信息在哪里找”和“填完后如何验证”。先确认能够看到影片，再检查播放、字幕、音轨和继续观看。网易爆米花各端的操作截图按对应版本维护。

Infuse 官方提供 Emby 原生接入。Apple TV 端可从设置中的共享入口添加媒体服务器；iOS 和 macOS 端从添加文件中的媒体服务器入口进入。[Infuse 官方媒体服务器连接教程](https://support.firecore.com/hc/en-us/articles/360006462093-Streaming-from-Plex-Emby-and-Jellyfin)

### 第四步完成 Apple TV 上手

提供独立的 Apple TV 教程，覆盖以下内容：

1. 按电视、网络连接方式和预算选择设备，说明购买渠道、保修和配件。
2. 连接电源、HDMI 和家庭网络，完成首次设置。
3. 说明 Apple 账户、所在地区的 App 可用性与付款方式，安装网易爆米花或 Infuse。
4. 演示 Infuse Pro 的选购、购买和恢复购买，附官方说明。
5. 连接 Emby，播放示例影片，检查字幕、音轨和观看进度。

首次设置可遵循 [Apple 官方设置教程](https://support.apple.com/zh-cn/102451)。设备选择和影音设置教程应记录所用机型、系统版本及电视条件，便于用户判断是否适用。

### 第五步验证持续入库

第二次加入一个新文件，检查它是否完成整理、是否被 Emby 收录，以及播放器是否能看到。分别说明“文件已整理”和“媒体库已收录”的含义，让用户知道出问题时应该检查哪一步。

## 优质资源与选片内容

资源内容同时解决“哪里找”和“怎么选”。建立持续维护的资源指南，介绍内容类型、获取方式、画质、字幕和设备适配条件；具体入口随内容更新维护。

入门教程可使用创作者提供下载的影片、开放电影或用户已有的视频。比如 [Blender 开放电影](https://studio.blender.org/films/)可作为选片和示例素材入口，下载与再利用按具体作品页面的许可执行。

后续内容可以覆盖影片推荐、创作者官方发布渠道、可下载的独立短片，以及用户已有收藏的整理方法。流媒体推荐需注明观看方式，避免让用户误以为平台内观看或离线缓存的影片都能导入 Emby。

“优质”不只看分辨率。教程要教用户结合片源质量、码率、字幕、音轨、设备解码能力和家庭网络选择版本，并用实际播放效果说明差异。

## 自媒体运营

### 内容主线

围绕“低成本拥有自己的家庭影院”持续输出内容，每篇解决一个具体问题，给出可复现步骤和明确结果。

| 栏目 | 首批选题 | 对应目标 |
| --- | --- | --- |
| 低成本入门 | 不买 NAS，电脑加移动硬盘怎么搭家庭影院 | 帮用户判断自己能否开始 |
| 播放器上手 | 网易爆米花怎么连接自己的 Emby | 完成第一次播放 |
| Infuse 使用 | Infuse 怎么买，买完怎么连接媒体库 | 帮助有升级需求的用户完成配置 |
| Apple TV | 从接上电视到播出第一部电影 | 打通客厅观影流程 |
| 文件整理 | 下载了一整季剧，怎样整理成清晰的媒体库 | 展示 MM 的日常价值 |
| 资源与画质 | 示例影片在哪里找，同一部影片怎样选版本 | 帮用户找到适合设备的内容 |
| 常见问题 | 电脑能看，电视为什么连不上 | 解决使用阻碍，沉淀反馈 |

### 渠道分工

初期建议先做小红书和 B 站：前者验证用户问题和选题，后者承载完整操作教程。待流程和内容模板稳定后，再扩展到抖音、视频号等渠道。

- **小红书：**设备组合、成本拆解、前后效果对比、短步骤图文。
- **B 站：**完整搭建、播放器配置、Apple TV 上手和故障排查。
- **抖音与视频号：**用短视频演示一个结果或解决一个问题，引导查看完整教程。
- **官网文档：**维护步骤、版本差异、下载入口和常见问题，各平台引用同一份基础资料。

同一个主题复用录屏和截图，按渠道调整长度。每份教程标明操作系统、App 版本和适用设备；产品更新后优先修正文档，再同步更新相关内容。

### 从内容到产品

内容展示实际观影效果 → 用户选择设备方案 → 按教程完成首次播放 → 持续下载产生整理需求 → 使用 MM 自动整理 → 将问题反馈补进产品和教程。

后续商业转化建立在免费工具持续使用的基础上：有需要的用户体验官方 API，再按需购买；托管通知等服务具备持续价值后再引入会员。教程保持完整可用，不把付费作为完成基础整理的前提。

观察完整教程访问、开始配置、首次播放成功和后续持续入库情况。产品具备相应记录能力前，可通过用户反馈和跟访收集。收藏、播放量和点赞用于判断选题吸引力，首次播放和持续使用用于判断方案是否成立。

## 推进顺序

1. **跑通样板方案：**用现有电脑、移动硬盘、Emby 和一个播放器，完成从文件到播放的完整演示，记录实际投入和问题。
2. **形成入门内容：**先完成低成本搭建、网易爆米花接入、Infuse 购买与配置、Apple TV 上手四组教程；补充可下载的示例影片入口。
3. **完善产品引导：**结合本机桌面端提案，逐步降低安装和目录配置门槛，明确 Emby 的安装、连接与收录状态。
4. **验证持续使用：**观察用户新增影片、追剧和修正识别的真实需求，决定后续产品投入与运营重点。

当前 MM 的文件识别、人工确认和整理能力可用于验证流程。免环境桌面安装、完整的新手引导及 Emby 交付状态仍属于桌面提案范围。教程可以先帮助用户手动完成配置，再把反复出现的操作逐步收进产品。
