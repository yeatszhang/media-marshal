# Mac 云端下载内测

当前客户端已接通夸克账号、目录浏览、一次性范围预览、目录订阅、下载队列和完成目录。账号只需在应用内连接；不需要单独安装 OpenList、Rclone 或 Docker。自动整理与 Emby 收录仍在开发中，下载完成不会显示为已入库。

## 开始下载

1. 在「云端网盘」连接自己的夸克账号。首版输入本人 Cookie，提交后清空输入且读取接口不回显；产品内暂不提供扫码登录。
2. 选择独立的本机受管下载目录，应用安装与私有数据位置不能作为下载根。应用在其中建立 `.media-marshal/staging` 和 `completed`，不要将该根同时配置为普通来源或媒体库目标。
3. 浏览并预览一个文件或目录，选择下载位置，再点击「预览下载范围」。只有扫描完整、目录可用且空间足够时才能确认下载；不完整计数不代表最终范围。
4. 在「云端下载」查看阶段、速度、已完成项和失败原因。总量未知时不显示百分比；页面重载只查询已有作业，不重新发起下载。
5. 文件通过长度、可用远端证据和本地摘要核对后进入 completed。点击「打开完成目录」可以使用已下载文件；整理尚未启用时显示待接入。

## 目录订阅与增量

选择目录后将下载方式改为「订阅目录」，可设置扩展名、精确文件名和扫描间隔（最短一分钟）。过滤使用字面文件名，不解析通配符或命令参数。首次与每次配置更新都必须完整预览后确认；配置更新生成新版本，旧版本不能继续领取新任务。

订阅按照网盘根下的相对目录存储，例如父目录 `/影视` 与子目录 `/影视/S03` 的重叠文件都映射到 `completed/影视/S03`。同一账号、版本、下载根和目标槽位只保留一个写入者，不同订阅拥有各自需求；取消一个需求不停止其他需求仍需要的传输。订阅范围预览中会显示目标相对路径。

应用运行期间按间隔扫描；应用退出期间不执行，重新启动将错过的周期合并为一次补扫。手动、周期和唤醒的重叠触发合并，不回放每一个错过的周期。分页失败显示扫描未完成，不把局部范围视为完整，也不因缺少条目删除本地成果。扫描完成与下载完成是两种状态。

增量复用会重新核对本地文件身份、长度和摘要。被删除、修改或替换的本地成果进入待处理，不仅依据历史记录跳过；同尺寸的可靠远端版本变化遇到已有目标会显示冲突。弱证据仍可能漏掉同尺寸远端替换。「强制重新下载」写入独立的 `completed/redownload-<预览ID>`，保留原成果。

## 暂停与恢复

暂停先停止新领取，等待当前传输真正退出后显示「已暂停」。暂停过程中不能立即恢复或启动第二个写入者。恢复保留已提交文件，为未完成文件建立新 attempt；**未完成文件可能从头重新下载**，首版不承诺跨进程字节级续传。

「暂停全部云端下载」独立持久化，只恢复由该操作暂停的作业；用户单独暂停的其他作业不会被恢复。订阅仍可扫描，新的需求等待云端下载恢复。本地整理的暂停状态独立保存。

取消保留完成文件和历史，只清理当前任务拥有的暂存区。如果其他作业仍需要同一文件，共享传输会继续。界面关闭后应用继续在后台运行，显式退出才停止应用。

凭据失效时重新授权；当前普通夸克接入无法核实账号 UID，重新授权后可能需要重选远端范围。限流按账号退避且自动尝试有上限，网络错误不会无限高速重试。

## 文件与磁盘

下载不会写入网盘，不因远端删除而删除本地成果，也不覆盖同名目标。目录穿越、符号链接、大小写/Unicode 碰撞或目标被其他进程占用时阻断受影响文件。

Mac 首轮真实文件验证使用 APFS。应用核对原卷 UUID、目录身份及实际提交能力；原磁盘断开或同名路径被替换时停止写入，不自动创建替代目录。NAS/SMB 等文件系统尚不支持自动落盘，其他系统或 Mac 架构只在各自通过验收后提供安装包。

普通夸克驱动目前只有路径身份和弱版本证据，同尺寸内容替换可能无法识别。本地 SHA-256 用于文件归属和恢复核对，不等于从夸克获得了端到端摘要保证。

单次预览上限为 10000 个远端对象和 16 MiB 私有快照，超限会要求缩小范围；单项自动尝试最多三次。组件保留当前代际的执行收据；每 128 个不同终止执行会暂停领取并受管重启 Core/Host，确认旧写入者回收后恢复调度。维护期间未完成文件可能重新下载，已提交成果保留；不通过淘汰旧收据换取容量。空间预检包括暂存和启用时的媒体 COPY；staging 与 completed 在同卷上共享已校验内容，不自动删除来源节省空间。

## 内测证据与限制

Mac arm64 上已完成用户指定 604951500 字节视频的真实窗口下载、校验提交、重载与 Core 重启核对，并通过真实 Rclone 的暂停/恢复/取消；记录位于 `tools/desktop-sidecars/fixtures/`。该视频的单次约 27.8 秒结果仅反映本次 VIP 账号和环境，不作为下载加速、普遍吞吐或 NAS 兼容承诺。

目录订阅也已通过同一真实视频的完整下载、按本地证据复用及暂停后的重载/Core 重启验收，脱敏记录见 `quark-subscriptions-v4.2.7-rclone-v1.75.2.json`。

当前没有 Developer ID 和公证配置，安装包只用于未签名内测。正式签名/公证、完整安装态故障矩阵、整理和 Emby 交付分别保留未完成状态。


## 手动整包升级和恢复

在设置中点击「准备升级并退出」。客户端先停止账号操作、核心和全部组件，等待凭据更新结束，再在本机 `private-backups` 受限目录保存匹配快照，完成后退出。替换整个 App，不单独更新 OpenList 或 Rclone。首次打开新版本也会在版本变化时保存旧状态；未声明版本的旧格式记录为未知，实际兼容性由核心检查。

需要回退时，从设置或应用菜单「恢复升级备份」选择匹配快照。恢复前再备份当前状态，恢复后退出，安装匹配版本后重新打开。旧版本会拒绝比自身新的数据库。恢复后历史完成文件先等待本地证据核对；缺盘或文件改动会保留待处理，不自动覆盖文件。备份不包含下载文件或媒体库，也不进入普通诊断导出。
