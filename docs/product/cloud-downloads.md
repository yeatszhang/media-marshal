# Mac 来源、下载与整理内测

客户端通过统一来源管理网盘与本地目录，分别记录下载、人工确认的 COPY 整理及已有 Emby 的交付状态。账号只需在应用内连接，不需要单独安装 OpenList、Rclone 或 Docker。统一页面已通过窗口检查，并在维护者自己的 Mac 完成一项真实下载至已有 Emby 收录的闭环，见[本轮验收记录](../architecture/mac-unified-source-validation.md)。下载完成、文件整理和 Emby 收录仍分别核对。

## 开始下载

1. 在「网盘账号」连接自己的夸克账号，填写账号名称并点击「打开扫码登录」。在独立窗口用手机扫码确认，应用自动验证连接；也可使用「手动 Cookie」。关闭登录窗口或点击「取消扫码」可取消，五分钟未完成则超时。网页会话结束后清理，不读取现有浏览器登录信息。连接账号本身不创建来源或下载。
2. 在「来源」添加网盘来源，填写名称并选择账号。通过远端浏览器选择一个文件、目录或网盘根目录；本地目录通过系统选择器授权。取消选择保留原草稿，从来源跳到账号页连接后返回也保留草稿。
3. 选择独立的本机下载目录。应用在其中管理 `.media-marshal/staging` 和 `completed`；不要将下载根同时配置为普通本地来源或媒体目标，应用安装与私有数据位置也不能作为下载根。已知同一目录重选会复用原授权。
4. 默认为只下载，不需要 TMDB、媒体目标或 Emby。按需设置扩展名、精确文件名及周期扫描；文件不能开启目录周期。启用「下载后整理到媒体库」时，另选媒体目标和所需媒体类型，不需要再新建本地来源接管 completed。
5. 「保存草稿」不启动任务。「预览配置」完整枚举范围，显示数量、大小、复用与冲突及实际完成路径；不完整计数不是最终范围。「确认配置生效」保存有效配置，「确认并执行一次」同时持久化配置和一次性执行意图，不开启周期扫描；周期来源的「确认启用并扫描」启动首轮扫描。已有来源可执行一次或立即扫描。
6. 在「云端下载」查看阶段、速度、已完成项和失败原因，并可定位来源配置。总量未知时不显示百分比；重载只查询已有记录。文件通过长度、可用远端证据和本地摘要核对后进入 completed，可打开完成目录。只下载显示「未启用整理」，历史归属不明则显示待核对。

## 看懂来源配置

表单顶部先显示文件去向：「网盘内容 → 下载到本地 → 可选整理到媒体库」。下方的「当前配置会怎样运行」会随选项更新，说明何时下载、下载完成后做什么。

| 配置 | 决定什么 | 与其他配置的关系 |
| --- | --- | --- |
| 网盘账号、远端范围 | 从哪里取文件 | 连接账号后，再选择文件或目录 |
| 扩展名、精确文件名 | 下载哪些文件 | 两项都填时需同时满足；都留空则不过滤 |
| 本地下载目录 | 下载文件保存在哪里 | 开启整理时仍保留这里的原文件，媒体库另选目录 |
| 定期检查网盘目录 | 何时检查新增或变化文件 | 默认手动；开启才显示扫描间隔，单个文件不支持周期扫描 |
| 下载后整理到媒体库 | 下载完成后是否进入识别与待处理 | 开启后填写整理目标和媒体类型；在待处理预览并确认后才复制 |
| TMDB 与 Emby | 识别作品与核对收录 | TMDB 用于整理识别；Emby 在复制到媒体库后刷新并核对收录 |

「保存草稿」只保存填写内容；「预览配置」核对影响范围；预览中的确认按钮才会使配置生效。同一窗口里去账号或设置页再返回，未保存输入继续保留；完整重载后只恢复已保存的核心草稿。

窄窗口下改为单列；开启周期扫描才显示间隔，开启整理才显示媒体库目标和媒体类型。可查看[开启周期与整理的窄窗口截图](/desktop/source-form-cloud-organize-minimum.png)和[本地来源截图](/desktop/source-form-local-minimum.png)。截图来自隔离目录下的当前 arm64 目录包，系统目录对话框使用受控替身，未操作个人媒体或账号。

## 本地来源与可选整理

本地来源选择「本地目录来源」，分别授权本地输入目录和整理目标。新建仅提供夸克客户端标签与自定义目录，不代表账号授权；历史百度、阿里等标签保留原值，按行为未验证的普通本地目录处理，仍需人工确认，不转换为夸克账号。保存、预览和确认与网盘来源使用同一个入口。

本地来源可选择默认忽略、关闭可配置忽略或自定义忽略。默认跳过隐藏项、临时文件、系统索引及 sample／samples 目录；自定义每行一条，文件名支持通配符，目录名以 `/` 结尾，替换默认规则。更改需重新预览确认后生效；关闭忽略也不会绕过稳定性检查或接入应用私有暂存文件。只有同目录存在精确同基名主视频时才跳过样片，不会仅因影片名含 sample 就跳过。

启用整理后，文件仍须经过稳定观察、识别和人工确认。在「待处理」选择作品并预览实际目标，确认后才 COPY，保留原文件。共享下载的相同整理策略复用候选；重叠范围要求不同目标或策略时，配置预览会指出冲突来源并阻止确认。completed 中没有登记下载证据的外部文件不会被自动认领。

使用已有 Emby 时，在设置中填写地址并保存密钥，读取服务器和媒体库后核对目标映射。来源配置使用各自选择的媒体目标；单个目标缺盘时等待原目录恢复。文件 COPY 成功后才进入独立交付状态，Emby 离线仅重试交付，不重新下载或复制，不修改服务器既有库配置。

电影或剧集可以单独配置，媒体目标可为已有库根目录或库内子目录，不要求清空原有内容。电影／剧集专用库应选择相应的来源媒体类型；同一目标自动接收两类媒体时，选择 Emby 的混合库。重新打开客户端后会自动复核连接，短暂显示「连接尚未验证」后更新结果；暂时离线保留绑定，认证或库配置错误需要在设置修复，不会自动安装或重配服务器。

文件显示「已整理」而交付尚未完成时，先检查 Emby 地址与服务状态；密钥或权限错误需要在设置中修复并重新验证连接。核对超时还需检查服务器库是否包含目标目录、是否能读取文件，以及 Emby 的作品标识和季集是否正确。修复后在任务中选择「仅重试 Emby 交付」，保留现有文件和整理历史。标题相同、扫描请求被接受或只找到另一个版本，都不代表此文件已收录；证据通过后才提供「打开 Emby」，用系统浏览器打开已配置服务器的条目页面，地址不带密钥。

任务页每页显示二十五条记录，可按文件状态筛选。停留页面时自动更新文件和交付状态，离开后停止轮询；查询恢复不会自动重试交付。Core 暂不可用时可使用恢复入口，重载页面后重新读取本机持久记录，不重复提交整理。

## 目录订阅与增量

在网盘来源勾选「定期检查网盘目录」，设置过滤与扫描间隔（最短一分钟）。过滤使用字面文件名，不解析通配符或命令参数。首次与每次配置更新都必须完整预览后确认；有效配置保留到新版本确认，保存新草稿不会改变当前执行策略。

订阅按照网盘根下的相对目录存储，例如父目录 `/影视` 与子目录 `/影视/S03` 的重叠文件都映射到 `completed/影视/S03`。同一账号、版本、下载根和目标槽位只保留一个写入者，不同订阅拥有各自需求；取消一个需求不停止其他需求仍需要的传输。订阅范围预览中会显示目标相对路径。

应用运行期间按间隔扫描；应用退出期间不执行，重新启动将错过的周期合并为一次补扫。手动、周期和唤醒的重叠触发合并，不回放每一个错过的周期。分页失败显示扫描未完成，不把局部范围视为完整，也不因缺少条目删除本地成果。扫描完成与下载完成是两种状态。

增量复用会重新核对本地文件身份、长度和摘要。被删除、修改或替换的本地成果进入待处理，不仅依据历史记录跳过；同尺寸的可靠远端版本变化遇到已有目标会显示冲突。弱证据仍可能漏掉同尺寸远端替换。冲突不会覆盖原成果，请核对范围、来源策略及保留的文件。

来源卡片的「强制重新下载…」先展示本次范围和独立完成路径，确认后写入 `completed/redownload-<预览ID>`，保留原成果。此操作不修改来源配置或周期扫描；全局暂停仍生效，重复确认会复用原执行意图。

原「目录订阅」导航已移除，旧链接定位到对应来源；无法确定时回到来源列表解释。升级保留旧 ID、路径、过滤、周期、暂停、共享需求和历史，不把一次性历史改成订阅，未知归属也不会自动套用当前整理策略。

## 暂停与恢复

暂停先停止新领取，等待当前传输真正退出后显示「已暂停」。暂停过程中不能立即恢复或启动第二个写入者。恢复保留已提交文件，为未完成文件建立新 attempt；**未完成文件可能从头重新下载**，首版不承诺跨进程字节级续传。

「暂停全部云端下载」独立持久化，只恢复由该操作暂停的作业；用户单独暂停的其他作业不会被恢复。订阅仍可扫描，新的需求等待云端下载恢复。本地整理的暂停状态独立保存。

「暂停来源」停止此来源的新扫描、下载需求及整理接入；其他有效来源仍需要的共享文件继续处理。「恢复来源」不会解除全局下载或全局整理暂停，也不会恢复用户单独取消的任务。来源页可独立暂停全部整理；已正式提交文件的 Emby 交付继续独立核对。

取消保留完成文件和历史，只清理当前任务拥有的暂存区。如果其他作业仍需要同一文件，共享传输会继续。界面关闭后应用继续在后台运行，显式退出才停止应用。

凭据失效时重新授权；当前普通夸克接入无法核实账号 UID，重新授权后可能需要重选远端范围。限流按账号退避且自动尝试有上限，网络错误不会无限高速重试。

## 文件与磁盘

下载不会写入网盘，不因远端删除而删除本地成果，也不覆盖同名目标。目录穿越、符号链接、大小写/Unicode 碰撞或目标被其他进程占用时阻断受影响文件。

Mac 首轮真实文件验证使用 APFS。应用核对原卷 UUID、目录身份及实际提交能力；原磁盘断开或同名路径被替换时停止写入，不自动创建替代目录。NAS/SMB 等文件系统尚不支持自动落盘，其他系统或 Mac 架构只在各自通过验收后提供安装包。

选择目录失败时，提示会区分本地来源／媒体目标／其他下载根重叠、应用私有目录、原卷或目录变化、权限不足、文件系统或提交能力不支持，以及管理标记不匹配。能确定冲突对象时显示关联配置 ID，可在对应配置中核对并修改映射。重新选择同一有效目录沿用原授权，取消选择保留原配置。 普通本地来源确认时，重叠提示会定位原来源名称和 ID；修改输入或目标后须重新预览确认。原目录失联时保留文件记录，恢复同一磁盘后重新观察稳定性，不把暂时不可访问当作删除，也不接管同名替代目录。

出现「目录管理标记无法与当前授权核对」时，先检查是否打开了原来的应用数据配置。目录中的 `.media-marshal/owner.json` 只能说明存在管理标记，不能证明当前应用拥有它；应用不会自动认领、覆盖标记或清理文件。可恢复原配置后重新核对，或选择独立的新下载目录，不要通过删除标记来绕过归属检查。

普通夸克驱动目前只有路径身份和弱版本证据，同尺寸内容替换可能无法识别。本地 SHA-256 用于文件归属和恢复核对，不等于从夸克获得了端到端摘要保证。

单次预览上限为 10000 个远端对象和 16 MiB 私有快照，超限会要求缩小范围；单项自动尝试最多三次。组件保留当前代际的执行收据；每 128 个不同终止执行会暂停领取并受管重启 Core/Host，确认旧写入者回收后恢复调度。维护期间未完成文件可能重新下载，已提交成果保留；不通过淘汰旧收据换取容量。下载暂存与媒体 COPY 分别在开始前核对空间；staging 与 completed 在同卷上共享已校验内容，不自动删除来源节省空间。

## 手动整包升级和恢复

在设置中点击「准备升级并退出」，核对原生确认窗口后选择「备份并退出」。默认取消；取消不会停止核心或创建备份。确认后客户端先停止账号操作、核心和全部组件，等待凭据更新结束，再在本机 `private-backups` 受限目录保存匹配快照，完成后退出。替换整个 App，不单独更新 OpenList 或 Rclone。首次打开新版本也会在版本变化时保存旧状态；未声明版本的旧格式记录为未知，实际兼容性由核心检查。

备份检查失败时，核心保持不可用，点击「重试」也会重新检查。请检查本机备份目录及权限，或从应用菜单恢复匹配备份；不要手动覆盖正在使用的业务数据库。

若提示某项本机凭据无法解密，请在设置重新保存对应密钥；该提示针对本机保存的密文，不代表 Emby 拒绝了原密钥。应用保留原密文，其他可用服务继续恢复。

需要回退时，从设置或应用菜单「恢复升级备份」选择匹配快照。恢复前再备份当前状态，恢复后退出，安装匹配版本后重新打开。旧版本会拒绝比自身新的数据库。恢复后历史完成文件先等待本地证据核对；缺盘或文件改动会保留待处理，不自动覆盖文件。备份不包含下载文件或媒体库，也不进入普通诊断导出。

已整理的主文件和字幕也会重新核对；核对时显示处理中，通过后再等待 Emby 收录核对。字幕冲突可独立处理，主文件不会因此重拷。核对不会解除全局整理暂停，也不会从来源重建被删除或修改的目标。
