# 修正已整理媒体

已整理的影片选错作品、季集或命名时，在「任务」找到文件，点击「修正」。修正只处理媒体库中的视频及其附属文件，下载目录中的原文件保留。

当前已验证 Mac Apple Silicon 的单条与同季／同剧批量修正页面和目录包。历史任务没有可信文件收据、文件已被外部替换或原磁盘不可用时，页面会阻断或等待核对。Intel 运行和正式签名发行仍按对应任务验收。

## 预览并确认

1. 核对「任务记录的媒体位置」，填写正确作品的 TMDB 数字编号和电影／剧集类型。剧集还需填写季号、起始集号及可选的合并结束集号；预览会重新校验真实分集，缺集或重叠会显示原因。
2. 选择修正后的媒体目标。这里只列出已授权目录；需要新目录时，先在「设置」授权，再返回重新填写。命名模板可留空使用默认值，也可展开「命名模板」填写。
3. 点击「核验并预览修正」。核验期间可查看当前文件的读取进度，或取消本次核验。此时还没有移动媒体。
4. 逐项核对作品、季集、新旧路径和保留项。默认一起处理同名字幕、NFO、封面及校验文件；通用 `poster.jpg`、`folder.jpg`、`cover.jpg` 留在原目录，校验文件只改名或移动，不改写内容。
5. 勾选已核对完整清单，再点击「确认并开始修正」。同卷使用安全移动或改名；跨卷先复制并核验新文件，再回收旧媒体目标。页面显示的「保留原位」项不计入执行进度。

修改任一参数会使当前页面的旧预览失效，需要重新预览。预览过期或 Core 重启后也需重新核验；窗口重载会恢复持久预览或作业状态，不会自动重新确认。

## 查看进度与历史

任务已有修正时，入口改为「查看修正进度」或「查看修正历史」。页面可跳到前一条历史及修正后的任务，也可从「修正记录」查看已确认作业。已修正的旧任务不会再走原整理入口。

「媒体文件与历史已完成」表示文件变更和历史记账完成；Emby 刷新与收录是后续独立步骤，到任务列表查看交付状态。确认期间取消核验，不代表撤销已经提交的作业；全局整理暂停会保留计划和现存文件，恢复后继续。

## 处理失败并重试

部分文件失败时，查看标红文件的新旧路径和具体原因。已经完成的视频保留，不会因为字幕失败而重新移动。

- 新位置被占用：核对该位置的文件，将不明文件移到其他位置保留，再点击「核对并重试原修正」。应用不会自动覆盖或删除它。
- 原磁盘离线、目录不可写或空间不足：恢复原卷、读写权限或可用空间；等待中的原步骤会继续，需处理的作业可从详情重试。
- 文件位置或内容与计划不符：展开「查看恢复核对位置」，结合原位置、新位置和可能的隔离／暂存位置核对。记录的位置不能证明文件仍在那里。保留不明文件和私有恢复文件，恢复与收据一致的文件或备份后再重试。
- 安全修正组件不可用：已有记录仍可查看，请使用组件完整且匹配当前架构的客户端恢复原作业。

重试沿用原作业、文件计划和新任务编号；证据充分时补记历史，证据不足时继续保留待处理。数据库备份回退不会撤销已经发生的媒体文件变更。


## 同季／同剧批量修正

在已完成剧集的单条修正页选择「同季／同剧批量修正」。范围限定为相同来源、整理策略和原作品的已完成剧集，从数据库完整计算，包含任务列表之外的其他分页。

1. 选择同季或同剧，填写正确剧集的 TMDB 编号。季集沿用每个成员的原记录，并在预览时按真实分集重新校验；需要单独调整季集时先使用单条修正。
2. 选择保留各成员原媒体目标，或统一使用一个已授权目标；可填写统一模板、选择是否同时处理同名附属文件。
3. 在完整范围中核对成员，逐页取消不参与本次修正的文件。跨页选择保留；恢复旧批次或重新读取时范围变化，会恢复全选并提示重新核对，需要重新排除不参与的成员；被排除成员也保留在范围变化检查中。
4. 点击「核验并生成批量预览」。后台显示当前文件读取进度，尚未受理时可以取消核验。参数编辑和预览不会移动文件。
5. 展开每个选中成员的完整清单，核对作品、季集、新旧路径、字幕及保留项，再勾选该成员。核对数量覆盖全部分页；全部成员核对后，还需确认理解可能部分成功，才能开始整批修正。
6. 批次显示范围、选中、完成与需处理数量。局部失败会定位到成员和逐文件原因；修复原卷、权限或占用后，重试原成员作业，其他已完成成员保持原结果。

「批量修正记录」同时保留未确认预览、核验中断和执行结果。窗口重载只读取原记录；尚未确认时需重新勾选完整清单，Core 重启会使未确认预览过期。调整范围或参数会创建新预览，不自动确认旧计划。

历史已记账但恢复后的媒体目标仍待核对时，页面会显示等待核验，不将该成员计为当前已完成；不会为恢复核验重新移动媒体。Emby 收录仍在各修正后任务中独立查看。批次只在全部复核通过后统一登记执行意图，实际文件与历史按成员推进，可能部分成功，不提供整批自动回滚。
