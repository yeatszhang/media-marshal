# 首次入库记录模板

配合[Mac 内测验证准备](./desktop-beta-validation.md)使用。每次尝试复制一份，默认在参与者本地填写；分享时只保留本表所需的脱敏字段。本表没有自动上传逻辑，不填写媒体名称、绝对路径、Emby 地址、账号 Cookie 或任何密钥。

## 基本记录

| 字段 | 填写 |
| --- | --- |
| 参与者编号／尝试编号 | U-__／A-__ |
| 日期与时区 | 例如 YYYY-MM-DD，Asia/Shanghai |
| 样本类别 | 外部参与者／维护者技术验证 |
| 安装来源 | 已验收内测安装包／工作区构建；填写版本和产物校验值，不填写个人文件路径 |
| 架构、系统、签名状态 | 按产物说明填写；不清楚的项填“未知” |
| 来源路径 | 夸克应用内下载／夸克客户端本地目录／自定义本地目录 |
| 客户端、Emby 版本 | 如适用；不记录服务器地址或账号 |
| 存储与目录关系 | 文件系统类型（可填未知）；输入和目标独立／原先存在重叠 |
| 样本 | 电影／普通剧集单集；文件数量和大小范围，不填标题或文件名 |
| 既有条件 | 已有 Emby、TMDB Key 是否就绪；是否初次使用此工具 |
| 本次目标 | 单个样本达到 Emby 已收录；播放验证另记 |

## 本次结论与跟访

| 字段 | 填写 |
| --- | --- |
| 安装／配置是否独立完成 | 分别填是／否／不适用，不把有协助结果改为独立成功 |
| 首次收录 | 独立成功／有协助成功／未完成／放弃／等待反馈 |
| 播放验证 | 成功／失败／未验证 |
| 是否需要修改作品或季集 | 次数与问题类型；正常人工确认次数单列 |
| 是否准备继续使用 | 仅作主观反馈，不等同持续使用 |
| D2～D7 是否新增内容 | 有／没有／未反馈 |
| 是否再次整理／收录 | 次数、是否成功、是否需要支持；复用旧成果不算新增入库 |
| 未再次使用的原因 | 无新增机会／原方案足够／步骤复杂／错误未恢复／其他具体原因 |
| 一周累计支持成本 | 分钟与往返次数；未记录不能填零 |
