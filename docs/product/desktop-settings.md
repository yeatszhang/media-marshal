# 客户端设置与运行方式

从侧栏打开「设置」。服务连接、媒体目录和本机运行方式分别保存；修改输入不会自动整理文件，也不会扫描全部历史媒体。

## 默认本地下载目录

点击「选择本地下载目录」通过原生目录窗口授权，或从已有受管目录中选择，再点击「保存默认目录」。仅选择、取消目录窗口或修改下拉选择不会更改默认设置；未保存的选择会在页面附近提示。中文、空格和长路径在目录下方完整显示。

默认目录由独立的目录引用和设置版本保存，供同步来源与识别输入解析使用。规则确认时冻结实际目录及默认设置版本，更换默认值不会移动文件或改写已有快照。原卷不可用时保留原路径并提示恢复原磁盘，不能把同名替代磁盘当作原目录。受管完成区应复用受管根，不能把其私有暂存或内部目录按普通目录接管。

2026-10-28 目录基础阶段：29 项目录、组件、契约和设置回归通过；开发构建实际窗口验证取消、选择后未保存、明确保存、更换默认值、重载和 Core 重启，原成果内容与 inode 保持，未产生下载或整理任务，920×640 长路径布局通过。目录对话框为受控替身，未访问个人目录或账号。来源与独立识别页面的完整接线仍在实施，此阶段不代表对应 OpenSpec 整项完成。

## 服务连接与代理

填写已有 Emby 的 HTTP(S) 服务地址，再分别保存 Emby 和 TMDB 密钥。Emby 地址可以包含反向代理的基路径，例如 `https://media.example/emby`，不能把密钥、账号密码或查询参数拼进地址。密钥只在客户端输入，保存后输入框清空，普通查询不返回原文。

「TMDB 代理地址」只用于 TMDB 查询，支持 HTTP(S) 代理，例如 `http://127.0.0.1:7890`。留空表示直连；地址不能包含账号、密码、子路径、查询参数或片段，不支持在这里填写 SOCKS 地址。Emby 和网盘连接不继承这项 TMDB 代理。页面会在提交前指出不合法字段，核心仍独立校验，错误输入不会替换已保存配置。

媒体目录在同页单独配置，电影和剧集可按需选择，不要求一次配齐。已有来源的输入目录、下载目录、整理目标及周期扫描从「来源」配置；详细流程见[来源与下载](./cloud-downloads.md)。

地址输入是本页草稿，保存密钥或刷新状态会保留尚未保存的 Emby／代理地址。离开设置或完整重载后重新读取已保存配置；需要保留地址修改时先点击「保存」。

需要重新加载界面时，可从「视图 → 重新加载界面」操作。客户端先清理当前页面再刷新，后台核心和已提交作业继续运行；重新打开后读取已保存状态。清理失败或超时会提示退出重开，不会将任务显示为已撤销。未保存输入不会通过重载自动保存或执行。

## 关闭窗口与登录启动

关闭窗口后应用继续在托盘运行。可从托盘重新打开窗口，选择「退出」才会停止应用；退出、注销或关机后不继续处理。任务停止和文件安全点仍按原作业规则执行，关闭窗口不代表撤销文件。

「首次关闭时提醒后台运行」默认开启，每次启动后的第一次关闭会说明后台行为。关闭这个提醒仍保留托盘运行。修改后点击「保存运行设置」，窗口重载或应用重开后继续使用保存值。

「登录后自动启动」默认不注册，只在 macOS 打包客户端提供。明确勾选并保存时才申请系统登录项；取消勾选并保存会撤回。启动、刷新和窗口重载只读取系统状态，不重新注册。如果显示「等待系统批准」，请到系统设置中的登录项允许该应用，回到客户端点击「刷新系统状态」核对；待批准不等于已启用。系统中手动更改的登录项也以系统当前状态为准。

![运行方式与关闭提醒](/desktop/host-settings-runtime.png)

运行偏好与业务库分开保存。业务备份恢复不重新注册系统登录项，关闭提醒保留当前本机偏好。若保存失败，页面会说明登录项是否成功恢复；请刷新系统状态核对，不要把未确认的响应当作已启用。

## 版本与开源许可

「关于与开源许可」显示当前应用版本、Electron 版本、目标架构及主要随包组件版本。点击具体组件可读取包内许可原文及来源说明；读取不依赖媒体核心或网络，不会下载替换材料。应用采用 GPL-3.0，其他组件按各自许可提供。

如果许可材料缺失或不可读取，页面提供具体组件和重新安装完整客户端的动作。版本和架构用于核对安装包，是否完成正式签名、公证及其他架构验收以对应发行记录为准。

## 导出诊断

点击「导出诊断」后，通过系统保存窗口选择位置。取消不写文件；导出内容只包含版本、平台、组件状态、计数和受限错误分类，不包含密钥、媒体名称、个人目录、业务数据库、组件私有配置或升级备份。诊断文件保存在本机，不会自动上传。

## 手动整包升级与恢复

点击「准备升级并退出」后，先核对原生确认窗口。默认选中「取消」；取消不会停止核心、创建备份或改动媒体。确认「备份并退出」后才停止新接入、等待安全点并保存匹配备份，完成后退出。随后替换整个应用，避免单独替换内部组件。

「恢复升级备份」先选择匹配备份，再明确确认恢复并退出。恢复前会备份当前状态；数据库回退不等于撤销媒体文件，下载文件和媒体库仍保留。操作完成后使用匹配客户端重新打开，等待已有文件证据复核。具体边界见[升级与恢复说明](./cloud-downloads.md#手动整包升级和恢复)。

## 来源同步

「来源」主页面只配置本地／网盘输入、下载 target、有序路径过滤及周期。先保存草稿并预览，再明确确认范围；文件执行一次和显式重新同步分别预览。目标使用默认目录时显示实际绑定，只有明确勾选重新绑定当前默认目录才跟随新默认值。没有默认目录时可选具体目标，已保存草稿不会丢失。

本地输入通过原生目录选择授权，不需要账号。文件连续稳定至少 120 秒后仍须确认完整性，随后复制精确清单。未知客户端的周期只提示新文件待核对，不静默放行。网盘账号管理返回来源时保留未保存草稿；重新登录改变授权根后必须重选远端范围，其余字段保留。

全局同步下载暂停、单个来源暂停与识别暂停分开。来源须先暂停、到达安全点后才能删除，文件和成功历史保留，恢复后仍暂停。Core 重启后的原目录授权恢复期间显示等待，不以同名路径替换原卷。任务明细支持逐项状态与分页，通过地址中的作业标识恢复查询，重载不重放确认。

已同步成果被删除时，普通执行显示「已同步，本地已移除」并跳过，不要求重新下载；显式重新同步使用独立目录并保留旧历史。目标内容被外部改动或目录不可用时，先核对原文件和原磁盘，再重试原作业，不覆盖第三方文件。升级前配置通过「升级前配置核对」入口查看；独立接管后旧入口拒绝再次写入。
