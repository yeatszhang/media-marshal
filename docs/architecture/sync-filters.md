# 同步路径过滤

同步契约中的 `filters` 使用有序包含／排除规则，`compileSyncFilters` 是本地枚举与云端预览共用的匹配入口。云端将选定目录下的相对文件路径交给匹配器，传输仅接收预览冻结的精确清单，不在执行时扩大范围。旧扩展名和精确文件名筛选仍按原交集解释；新旧筛选混用的历史投影要求重新核对，不把交集转换成并集。

规则首个命中生效；无匹配默认包含。只选择电影文件的例子：

```text
- /private/**
+ *.{mp4,mkv}
- **
```

末尾的 `- **` 必须显式添加。开头 `/` 锚定所选目录，未锚定的规则可从任意路径段开始匹配。`*` 和 `?` 不跨目录分隔符，`**` 可跨目录；`a/**/b` 要求中间确有目录分隔符，不自动解释成 `a/b`。支持字符组、范围、`^` 字符组排除、同一路径段内逗号花括号备选，以及特殊字符的反斜杠转义。排除 `cache/` 等同于排除 `cache/**`。

暂不支持原始正则、嵌套花括号、花括号内跨目录或双星表达式、POSIX 字符组和仅目录包含规则。非法表达式在契约校验时给出具体原因。每条规则单独指定是否区分大小写，默认区分；旧扩展名忽略大小写与精确文件名区分大小写的行为保留。

本机与服务端路径不参与 glob 推测。匹配只选择文件，目录授权、卷身份、源就绪、目标冲突、成功历史、校验和与不覆盖发布仍各自核对。复制使用私有暂存，源删除不会触发目标删除。
