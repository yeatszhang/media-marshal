# Mac 夸克官方客户端磁盘观察

此记录用于本地目录接入的就绪判断，区别于应用内 OpenList／Rclone 下载。首次仅验证夸克网盘 macOS 官方客户端 7.4.2.822（build 2.822）、macOS 26.5.2 arm64、APFS 上一个文件的正常下载；来源仍要求人工确认，任务 4.1 保持未完成。

## 正常完成的实际证据

2026-10-25 在官方客户端选择独立的临时下载目录，完成 392,608,240 字节文件，摘要与此前已核对的同一资源相同。没有更改客户端限速、默认目录或系统网络设置，没有向媒体目标写入该样本。

使用目录事件和每 100 ms 的文件属性采样，实际观察到 `01-<随机标识>.mp4.qkdownloading`。临时文件从零字节增长至最终大小，随后改为 `01.mp4`，改名前后为同一文件身份。首次达到最终逻辑大小到正式名称出现相隔约 941 ms，期间修改时间仍发生变化；短暂尺寸不变或达到最终尺寸不能单独证明下载已完成。

版本化脱敏夹具 `tools/desktop-sidecars/fixtures/quark-official-macos-7.4.2.822-normal.json` 保存 77 条筛选后的相对时间记录、大小、块数和匿名文件身份。随机标识、原始 inode、绝对路径、账号和远端资源路径均不进入夹具；原始报告只留在本机私有验收目录。

| 场景 | 状态 |
| --- | --- |
| 正常下载及完成重命名 | 本版本、一个文件已观察 |
| 暂停及恢复写入 | 尚未观察 |
| 断网及恢复 | 尚未观察 |
| 专门的预分配故障场景 | 尚未构造；正常下载时的块数变化不能代替此项 |
| 同名重新下载 | 尚未观察 |
| 其他客户端版本、文件系统或平台 | 尚未验证 |

`.qkdownloading` 仅提供等待依据，不表示已取得官方完成回调。用同一后缀构造临时文件，再真实改名并验证重新稳定和单次 COPY，是回归测试；它不代替官方客户端暂停、断网或预分配实测。

## 实测时间线的流水线回归

2026-10-26 将上述 77 条正常下载记录接入 `packages/media-core/src/ingestion/pipeline.test.ts`。回归在隔离目录中按相对时间重放逻辑尺寸、修改变化和同一文件身份的正式改名；达到最终大小后、仍使用临时名称的三次观察均不能就绪。正式名出现后 119,999 毫秒仍等待，完整 120 秒且持续复查后才进入可识别状态，并继续要求人工确认文件完整。没有发出 TMDB 查询、创建媒体任务或 COPY。

临时名消失和正式名出现的两个属性收据相差 1 毫秒；回放在正式名收据处执行一次真实原子改名。样本使用稀疏测试文件，重放逻辑尺寸和修改变化，不复刻原下载内容、APFS 块分配或客户端完成通知。该测试验证既有实测输入在当前流水线中的处理，不是新的官方客户端下载记录，也不填补上表的未观察场景。

本轮定向 `npm test -- packages/media-core/src/ingestion/pipeline.test.ts` 为 75 passed，文档与 OpenSpec 严格校验通过。没有修改生产就绪规则，4.1／4.4 继续保持未完成。

## 只读观察工具

`tools/desktop-sidecars/observe-quark-files.mjs` 只读取文件属性，不读取媒体内容、控制客户端或修改偏好。显式传入观察根和私有报告绝对路径，报告必须位于观察根之外：

```bash
node tools/desktop-sidecars/observe-quark-files.mjs "/绝对路径/独立测试下载" "/绝对路径/私有验收/events.jsonl"
```

工具不覆盖既有报告，以 0600 权限新建报告；最多跟踪 128 个相对路径、记录 20,000 条变化，十五分钟结束。按 Ctrl-C 时先停止监听并等待在途属性读取，再最终采样和关闭报告，避免迟到事件写入已关闭文件。观察目录内的报告路径，包括软链接指向该目录的路径，在创建报告目录前拒绝，避免自身观察。

工具已用独立临时目录验证真实临时文件改名、SIGINT 完整结束、报告权限、媒体保留及报告放回观察根时的拒绝行为。工具验证不扩大上表的官方客户端兼容范围。
