# 受管下载副本清理

清理由 Core 的 `DownloadCleanupService` 编排，使用 schema v34 的独立日志。复制记账、Emby 收录及清理是三个结果：媒体可以已经整理完成，但下载副本等待共享需求释放或暂存仍需处理。

## 文件与证据

新整理确认事务为受管下载登记 `download_cleanup_intent`，主文件与已选择的附属文件各一项。只有整理步骤 `RECORDED` 后才核对成功同步收据和实际库内副本。启动只恢复已登记意图，不扫描历史成功文件来补造删除授权。

历史副本从“云端下载 → 下载副本与临时资源 → 清理历史下载副本”选择成功收据，或在完成任务的整理详情选择其原件。公开动作只接受收据、任务和预览 ID，不接受删除路径、grant 或摘要。预览后台完整读取文件；准备过程可以取消，准备完成后有十五分钟确认期。确认短事务复核当前授权并登记具体清理意图，随后持久执行器重新读取源与目标，不让大视频核验占用公开 RPC。

完整 SHA-256、精确大小、卷 UUID、根目录身份和文件 inode／出生时间／修改时间同时核对。文件名与大小、作品季集的大小比较和人工确认跳过都不是删除证据。Emby 绑定须有效，包含目标根与路径转换；独立识别逻辑目标可以复用设置目录的绑定。核验本机真实副本无需等待 Emby 索引收录。

在清理计划登记之前，若已整理视频随后被修正改名，可按完整内容重新找到当前库内副本；字幕和元数据仍只使用明确交付对应关系。消费者检查与修正领取边界同时覆盖原任务和当前目标路径，不能因修正产生了新的任务 ID 漏掉需求。

## 共享需求与删除

领取前检查所有同步作业、识别候选、生效识别输入、整理主文件与附属文件步骤、下载交接／写入 claim、修正核验及修正成员。暂停仍保留需求；同步终态、候选完成或显式放弃才释放。消费者检查与清理领取处于同一 SQLite 短事务，领取后触发器阻止原文件的新候选、候选重新启用及媒体修正消费者。

等待消费者时先查询持久需求，不在每轮调度重复读取大视频摘要。需求释放后才完整读取，领取事务仍重新检查一次，防止读取期间出现新消费者。

执行器先完整核验，随后使用 Main 注入且经过摘要校验的原生组件，把原件独占改名至固定操作 UUID 的私有隔离位置。最终删除前完整重读媒体目标，再检查隔离文件仍是同一对象，只删除该隔离文件。恢复根据持久阶段探测原件与私有文件，不领取原路径新出现的同名替代文件；删除已发生但记账未完成时只补记事实。

缺盘或 Main 尚在恢复授权时保留原阶段等待。内容、文件身份或绑定变化转需处理，隔离副本保留。显式重试可完整核验同一物理目标的当前绑定并追加不可修改的核验历史；目标目录、卷或文件变化不能借重试更换清理对象。媒体库原件不会由本清理所有者删除。

## 附属文件与临时资源

字幕、图片及 NFO 各自要求已交付且内容一致。字幕缺失、用户排除、NFO 被重新生成或图片不同都保留原件；主视频成功不授权递归删除同目录。清理后逐级使用非递归空目录移除，保留 `completed`、下载根、私有恢复目录和混合目录中的其他文件。

| 资源 | 所有者与回收条件 |
| --- | --- |
| 整理主文件／附属文件 attempt | 整理所有者先在正式记账事务登记 `owned_attempt_cleanup`，`RECORDED` 后回收匹配标记的单个 attempt |
| 下载 attempt | 下载所有者提供停止证据、释放 claim，且所有已有提交意图已记账后回收所属 attempt |
| 本地同步 attempt | 本地同步所有者在成功收据及 `RECORDED` 的同一事务登记回收，失败不改变同步成功；受管原件清理同时核对未完成的本地同步成员 |
| 隔离原件 | 独立清理所有者持有操作 UUID、同步所有权和源／目标内容证据，最终目标重验通过后删除 |
| TMDB 等共享可再生成缓存 | 继续由原所有者按有效期与容量回收，单个任务完成不清空其他任务的共享缓存 |
| 未登记文件、未知暂存、普通本地输入 | 不取得自动清理权限 |

暂存失败保存具体作业、路径、原因、已统计字节及重试入口，不再吞掉整理收尾异常。暂存字节为所属目录中的逻辑文件大小；硬链接与共享块可能使其不同于磁盘实际释放空间。统计或删除期间发现符号链接、未知所有权或恢复引用未释放时保留文件。暂存重试不重新复制视频，也不修改 Emby 成功状态。

## 查询与恢复

整理确认单项及批量范围说明受管原件的清理行为。完成任务的整理详情、云端下载页面显示等待阶段、共享需求原因、原件与库内路径、释放大小和失败重试。历史预览身份保存在当前窗口会话，重载只查询，用户确认才提交；Core 重启按数据库日志恢复。应用成功同步收据不改写，清理日志提供主动删除事实，补扫保持已交付候选，普通同步继续复用原成功收据而不补回下载副本。

本功能当前仅在 macOS 可信原生组件可用时执行删除；其他平台或原生资源缺失时保留文件并显示原因。自动化使用自建临时目录、隔离 SQLite 和后台 Electron 窗口，包含独占隔离、最终重验、同名替换、附属项、失败重试及五个阶段的真实 SIGKILL。它不代表已经清理 `/Volumes/Seagate` 下的个人文件，也不替代发行签名、其他平台和真实移动卷的完整验收。
