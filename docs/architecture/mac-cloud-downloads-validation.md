## 0.2.1 限流补丁

本节与上方 0.2.0 的真实账号/性能记录分开保存。0.2.1 修复非 JSON 的 HTTP 429 被归类为组件故障的问题；JSON 限流信封仍保留失败挂载的资源 ID，用于清理部分创建的挂载。持续限流测试验证两个同账号作业共享退避、每项最多三次尝试，耗尽后唤醒不重置预算。故障由测试 HTTP 服务及可控时钟注入，不是夸克自然限流的观测。

0.2.1 的完整回归为 188 通过、1 项条件跳过；类型检查、依赖边界和 Mac 目录包构建通过。新 DMG 只读挂载并核验 EROFS、实际版本及组件/许可/源码摘要，安装态窗口结果在 `mac-v0.2.1-validation.json` 单独记录。本轮未重新扫码或下载真实夸克文件，不把上方 0.2.0 的吞吐和恢复时间改记为新版本性能。

0.2.1 为 Apple Silicon 未签名内测，DMG 219451733 字节，SHA-256 `82734e9f005fffb160c9288bf84ef872e579f68d3f69b95dd30e17ea766a46ad`。整理/Emby 仍等待前案接收端，正式签名及完整限流验收仍未勾选。
