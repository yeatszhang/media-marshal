# 0.2.1 内测归档说明

归档日期：2026-10-26。构建标识：`ecfbdd2`。应用显示版本：0.2.1。

本页描述这一份已留档的 macOS arm64 DMG。产物未完成 Developer ID 签名、公证与完整发行验收，未在客户端下载页开放分发。架构、使用条件、完整 SHA-256 与核对方法见[客户端下载页](../download.md)。

## 这份构建包含什么

- 统一「来源」入口，配置夸克远端范围或已有本地目录；账号连接、下载、整理和 Emby 交付分别记录。
- 来源表单按文件去向分步展示，分别设置下载位置、周期扫描与下载后的整理。默认只下载；开启整理后再配置媒体库目标和所需媒体类型。
- 来源草稿、范围预览与明确确认分开。保存草稿不启动任务，执行一次不隐式开启周期；筛选、目录和规则变更需要重新预览确认。
- 文件观察、作品与季集识别、待处理确认和 COPY 整理；默认保留输入文件。已整理文件的修正与批次处理提供独立预览、历史和失败处理。
- 已有 Emby 的刷新与收录核对；下载完成、复制完成和已收录采用不同状态。
- 升级前停写备份、匹配备份恢复，以及恢复后对实际文件成果的重新核对。
- 来源卡片将编辑、暂停与删除操作放在目录健康信息之前，最小窗口下优先展示操作入口；筛选项收起后保留已配置状态。

以上为构建内的能力范围。真实账号、官方客户端行为与各类故障的覆盖情况仍以分项验收为准，不等于全部环境已经验证。操作入口见[来源与下载](../product/cloud-downloads.md)、[整理修正](../product/desktop-corrections.md)和[运行设置](../product/desktop-settings.md)。

## 已完成的内部安装检查

同一 arm64 映像完成只读挂载启动、中文与空格路径、覆盖安装、保留资料的卸载重装，以及历史桌面 DMG 的整包升级；来源与目标媒体保留。完整打包检查为 45 passed／3 skipped，补充备份摘要断言后另跑三项安装检查通过。

目录选择器返回值在这些窗口测试中受控；实际文件、卷授权、数据库迁移和备份使用生产实现。此安装记录不替代真实系统选择器、Finder 拖放、注销登录或账号下载检查。构建摘要与逐项范围见[Mac 安装态验证](../architecture/mac-installation-validation.md)。

## 已知限制

- 该归档实际运行环境为 macOS 26.5.2／Apple Silicon；Intel 和最低系统版本尚未完成验收。
- 未签名内测与正式发行分别记录，本页不提供绕过系统安全检查的安装步骤。
- 夸克官方客户端的暂停、断网、预分配和完成事件组合仍在补验。本地文件的大小稳定不代表下载完整，证据不足时需要用户确认。
- 自动整理需要首次预览授权和明确的完整性、识别证据；未知行为仍要求确认，共享来源的自动权限规则尚在核对。
- 未完成文件在暂停、退出或恢复后可能从头下载；不承诺跨进程字节级续传、下载加速或任意 NAS 兼容。
- 本构建的托盘尚未包含整理／云端下载独立暂停入口。该功能及持续 SIGSTOP 下的退出回归属于后续构建，不能用本归档验证。

当前仍在推进的完整任务范围见对应 OpenSpec 变更；架构与验收记录中的后续结果不改写本页归档的身份。

## 升级与许可

升级前先在旧客户端完成「准备升级并退出」，替换整个 App；恢复旧版本须使用匹配备份。媒体文件不会随业务数据回退而自动撤销。

应用与随包依赖的许可、来源和版本可从客户端「关于与开源许可」读取。桌面包包含离线解析器、数据库原生模块及应用内夸克下载组件，不要求旧 Java、Docker 服务或用户安装 Node／Python。
