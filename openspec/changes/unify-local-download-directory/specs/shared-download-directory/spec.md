## ADDED Requirements

### Requirement: 设置唯一下载目录
系统 MUST 仅在设置页配置本地下载目录。来源与识别不得提供覆盖目录或识别客户端选择，电影与剧集媒体目标也 MUST 只在设置页按类型配置，识别页只读展示并直接使用设置值。

#### Scenario: 未设置目录
- **WHEN** 用户编辑来源或识别规则且下载目录未配置
- **THEN** 显示未设置与前往设置入口，不能执行同步或识别

### Requirement: 目录切换与任务冻结
系统 MUST 让新同步预览和识别输入使用当前设置目录，保留已受理任务路径及成功历史。

#### Scenario: 更换下载目录
- **WHEN** 用户保存新的下载目录
- **THEN** 新任务使用新目录，未确认旧预览失效，已受理任务沿原计划恢复，不移动既有文件

#### Scenario: 删除同步成果
- **WHEN** 同一源版本已成功同步而本地成果被删除
- **THEN** 普通同步不补下载，只有显式重新同步可以再次传输

#### Scenario: 管理标记不匹配
- **WHEN** 目录现有标记无法与授权核对
- **THEN** 提示目录身份不匹配原因和重新选择的修复动作，不接管或清理原文件

### Requirement: 识别复用设置媒体目标
识别表单 MUST 不提供重复选择、增删、类型或命名模板编辑入口。保存与范围预览 SHALL 使用当前设置中的电影、剧集媒体目录；已授权目录及 Emby 关联 SHALL 复用，历史规则目标不得作为当前设置默认值。已受理文件操作 MUST 保留冻结目标。

#### Scenario: 设置已配置媒体目录
- **WHEN** 用户添加或编辑识别规则
- **THEN** 展示设置中的电影、剧集路径，保存时直接用于对应类型的整理，不要求再次选择目录或配置 Emby 关联

#### Scenario: 设置缺失或目录不可用
- **WHEN** 某类型媒体目录未设置或原磁盘不可用
- **THEN** 明确展示该类型的缺失或不可用状态并提供前往设置入口，不以其他类型或历史目录代替

#### Scenario: 编辑期间设置变化
- **WHEN** 用户修改设置目录后返回识别草稿
- **THEN** 目录展示与下一次保存采用新设置，不覆盖已编辑的规则名称；保存后仍须预览确认范围，已受理文件操作保留原目标
