# Emby 安装与初始化

## Purpose

帮助尚无可用本机 Emby 的用户完成可信安装、启动、首次账号和媒体库配置，并安全进入已有的下载整理与收录链路。操作需可恢复，能够区分已有服务器和新建实例，避免破坏用户现存配置与媒体。

## ADDED Requirements

### Requirement: 区分已有服务器与新建实例

向导 SHALL 提供接入已有服务器与新建本机服务器两条入口。安装前 MUST 核对已有安装及服务状态；不可达不能直接视为未安装。已有已初始化实例不得自动重装、重置账号或改写媒体库。

#### Scenario: 已安装但服务未运行
- **WHEN** 检测到已有 Emby 安装而连接暂时失败
- **THEN** 向导说明状态并允许修复或显式启动后重试，不自动执行重装或首次初始化

### Requirement: 用户确认后的可信安装与启动

用户确认安装计划后，应用 SHALL 获取适配已支持平台及架构的可信 Emby 安装产物，核验来源和完整性并执行安装及启动。必要系统权限须通过系统交互取得。取消、下载失败或验证失败 MUST 不报告安装成功，也不得执行未验证产物。

#### Scenario: 安装文件验证失败
- **WHEN** 下载的产物不满足已固定的来源或完整性要求
- **THEN** 停止安装，保留可重试状态并解释原因，不启动该文件

### Requirement: 首次账号与媒体库初始化

对已确认归属且未初始化的新实例，应用 SHALL 按用户输入完成首次账号设置、媒体目录及电影或剧集库创建，验证服务器身份、目录访问和连接权限，再保存客户端绑定。密钥和密码 MUST 不进入日志或普通诊断。

#### Scenario: 只初始化电影库
- **WHEN** 用户仅选择电影媒体目录并确认初始化
- **THEN** 只建立对应账号和电影库，验证可访问后进入既有来源配置，不强制创建剧集库或搬迁已有文件

### Requirement: 初始化幂等恢复与安全交接

安装及初始化 SHALL 保存可恢复阶段，并在重试前读回真实服务器状态；不得重复建账号或媒体库。只有服务器、权限和目录绑定均核验成功才能交给既有交付链路；失败或取消不删除已存在的服务器数据或媒体。

#### Scenario: 创建媒体库后客户端崩溃
- **WHEN** 重启后恢复到媒体库创建步骤，服务器中该步骤结果已存在
- **THEN** 核对归属和配置后复用已有结果，不重复建库；无法证明归属时提示处理，不盲目覆盖

#### Scenario: 初始化后首次入库
- **WHEN** 新实例和目标绑定验证成功，用户确认一项媒体整理
- **THEN** 复用现有 COPY、刷新与收录核对，只有实际匹配到目标条目后才显示已收录
