# 桌面多语言支持提案

## 为什么

主变更需要先完成稳定的中文流程，完整中英文覆盖与语言切换会扩大界面验收面。将语言设置、翻译补齐及本地化验证独立安排，保留已实现的国际化基础。

本变更由 [add-local-desktop-emby-ingestion](../archive/2026-10-27-add-local-desktop-emby-ingestion/proposal.md) 于 2026-10-25 拆出，状态为后续待实施；不属于主变更的验收或归档前置。本次只迁移规划，不实施功能。

## 变更内容

- 承接主变更 7.6 的语言设置、20.3 的英文文案和 desktop-runtime 的中英文切换要求。
- 提供中文默认、英文可选、偏好持久化与缺失文案回退，覆盖窗口、托盘、原生应用提示及错误说明。
- 验证长文本、插值、数量与时间展示、键盘焦点及重启恢复；切换语言不重放业务动作。
- 不改变媒体名称、真实文件路径、TMDB 元数据语言策略或整理命名模板，不扩展更多语言作为首批门槛。

## 能力

### 新增能力

- `desktop-localization`：桌面语言选择、文案覆盖、回退、显示格式及业务状态隔离。

### 修改能力

无。当前主规格为空；本增量只定义后续扩展，不复制主变更的七份基础规格。实施前按当时已归档主规格复核能力边界及与本扩展有关的范围限制。

## 影响

复用 apps/desktop 中已安装的 i18next/react-i18next 和现有 cloud-i18n.ts 文案；补齐所有界面与宿主文案，不替换应用框架或业务状态机。

依赖主变更对应的运行、来源与交付基线。其他后续变更可独立排期，不隐含同时实施。原任务完成状态不迁移为本变更的完成证据。
