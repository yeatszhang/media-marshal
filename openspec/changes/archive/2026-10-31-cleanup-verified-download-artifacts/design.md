# Design

## Context

动机见 proposal.md。`IngestionPipeline.copy` 先完成内容校验、正式发布与数据库记账，再调用 `cleanupAttempt`；主文件与附属文件的清理异常目前被忽略，下载原件始终保留。`EmbyDelivery` 独立核对库根、路径、作品及季集，`COLLECTED` 不是本机内容摘要。同步去重已有 `CONTENT`、`MEDIA_SIZE`、`NAME_SIZE`、`USER_CONFIRMED` 证据，后三者不能作为删除凭据。

`ManagedRoot` 已有完整摘要、原卷／文件身份核对，以及配合私有原生组件的独占改名、隔离路径和隔离文件回收原语。`FileRelocations` 的日志与强杀测试可参考，但它负责媒体修正，不应直接认领下载原件。成功收据与识别接收记录分别由同步、识别所有者维护。

## Goals / Non-Goals

目标是让整理在内容核验后具备最终移动效果，并逐项释放本次作业的临时资源。普通本地来源继续只读；不删除网盘文件，不清空整个下载根，不回收通用浏览器缓存、凭据、成功历史或任意第三方临时文件。

规划阶段不实施代码、不启动个人媒体清理。实施以新确认事项为默认触发范围；历史副本的清理必须有独立范围预览。本变更的隔离验收不授权启动个人媒体清理。

## Decisions

1. **复制、交付与清理分开记账。** 新增独立清理所有者和持久阶段，候选须关联成功收据、整理结果或已验证的库内重复证据。不把清理失败写成整理失败；任务可同时显示媒体已交付和下载副本未能清理。
2. **库内文件存在指本机真实内容。** 核对当前 Emby 目标绑定及路径转换，并读取实际媒体文件，与受管下载原件进行完整 SHA-256 和大小比较。无需为了本机去重等待 Emby 索引刷新；反过来，服务器条目或刷新成功也不能代替本机内容证据。无本机可读文件、绑定待修复或原卷失联时等待，不猜测删除。
3. **只回收受管、已释放的单个对象。** 由各业务所有者检查同步需求、多个识别规则、附属文件、在途复制及修正的引用。暂停仍代表需求保留；清理领取与需求新增必须串行或使用同一持久租约，避免检查后新增消费者。普通来源、未知文件和来源接管前文件不自动删除。
4. **独占隔离后再删除。** 通过现有可信原生资源和受管根句柄，使用固定操作 ID 将已核验下载文件独占改名至私有隔离区；最终删除前再次完整核验媒体目标，再核对隔离文件仍为原对象。记录至少待核验、等待引用、已隔离、删除待核对、下载已清理、缓存待回收、完成和需处理阶段。恢复时保留实际阶段，数据库回退不能撤销文件动作。
5. **附属文件独立处理。** 只按已交付且完整内容一致的对应关系清理，视频匹配不授权删同目录其他文件。NFO 被重新生成、字幕未选中或图片不同时保留，并解释原因。用户可先释放主视频占用而保留未完成附属项；共享目录最终只做非递归空目录移除。
6. **缓存归所有者清理。** 列出下载 attempt、整理 attempt 和可再生成缓存的所有权及引用，完成恢复证据持久化后逐项交给所有者回收；保留失败重试，而不是增加无条件递归删除。下载成功记录仍不可变，追加清理事实解释本地缺失，补扫不把正常清理记为新错误或要求重下。
7. **UI 与授权。** 整理确认范围中说明完成核验后将清理哪些受管源文件；任务详情展示待清理、等待共享需求、已清理、失败及释放大小。历史批量回收单独预览，页面只传业务 ID，不传任意删除路径。真实个人数据删除须遵守仓库的具体范围告知规则，隔离自动化测试不代替该授权。
8. **重试保留原物理对象。** 原计划和所有权证据不可改写。当前绑定变化先停止；用户显式重试时，可在同一物理根、路径及原文件完整摘要仍一致的条件下追加绑定核验历史。更换目标或文件身份仍阻断，不把重试当作接管新文件的授权。历史预览确认仅短事务登记意图，完整重读由持久执行器承担；十五分钟确认期从预览核验完成后开始。

## Risks / Trade-offs

- 大视频完整读取耗时 → 后台持久作业、进度、取消与单盘并发限制；删除前的强验证不能降级为大小或缓存摘要。
- 文件读取后被替换 → 根句柄、原卷核验、独占改名及最终目标重验；证据不足保留隔离副本供恢复。
- 自动清理触发补扫误报或普通同步补回 → 成功收据保持，增加明确清理事实并更新相关状态投影与测试。
- 旧缓存无可靠所有权 → 保留并说明，不能把未知目录当垃圾删除。
- 当前阶段不保证非 macOS 原生文件操作能力 → 平台能力未验证时不自动清理，必须真实平台测试后开放。

## Migration Plan

实施时追加当前清理状态与证据结构，不创建新旧数据双轨，不为历史文件自动编造清理授权。先接入新增完成项的后台清理，随后开放独立历史清理预览。失败及回滚始终保留媒体库文件、成功历史和隔离证据；不能仅回滚数据库后重放文件删除。
