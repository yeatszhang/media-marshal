## Context

现有目录与批次查询、识别字段编辑、逐文件预览及 COPY 确认均已实现。截图中的扫描问题挤占首屏，用户无法在同一工作位置对照文件与识别结果。

## Goals / Non-Goals

目标是让目录批量成为默认入口，使未解决文件可连续人工核对，扫描问题和历史不阻挡主流程。保留深蓝导航、浅灰工作区、系统字体和既有交互控件。本轮不接入 AI，不改变自动授权、置信度、稳定观察、TMDB 季集核验或文件执行行为。

## Decisions

- 采用 Operate 模式。目录批量、逐个处理为主入口，季集辅助、扫描与问题、整理记录为次级入口。
- 目录列表与当前目录成员并排；自动选择首个可查询目录，只读加载不提交识别。选择限定当前页，仍按已有分组与每页上限执行。
- 从目录进入单项时，左侧保留该目录当前页队列，轮询既有目录查询以获取实际状态；可返回全部文件。文件搜索仅筛选当前页，不伪装成全量查询。
- 人工核对分为作品候选、作品／季集字段、整理预览。高分只表示识别依据，必须明确选择候选；命名和附属选项渐进展开。批量字段编辑仍为页面内专注任务，返回后保留列表位置。
- 生成批量预览后进入整理记录；取消草稿回到原队列。原确认勾选、过期校验、冲突与逐文件失败记录保持原行为。
- 文件切换清空旧 task 和 preview，页面显示读取状态；迟到响应继续由原有请求序列丢弃。失败显示可重试原因，不把上一项表单用于当前文件。
- 扫描入口显示当前扫描记录页的问题作业数量，不声称全量问题文件总数；详情仍分页、持久可查。

## Risks / Trade-offs

920 × 640 下保持两栏，表格在局部横向滚动，页面允许纵向滚动。目录和文件均保留既有分页，不引入跨页隐式全选；连续处理只覆盖当前页任务。UI 测试使用隔离数据库中的已解析任务，不代表真实解析准确率、120 秒文件就绪验收或安装态验收。

## Validation

定向组件测试核对只读浏览、范围保留、预览失效、读取失败、批量编辑和明确确认边界。Electron 当前构建窗口覆盖目录／文件工作台、扫描详情与 1440／920 宽度截图，并确认交互没有创建文件作业。执行类型和依赖边界检查；最终结果记录在 tasks.md。
