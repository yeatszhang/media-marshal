# Spec Delta

## ADDED Requirements

### Requirement: 完整识别策略的行为对照
桌面识别 SHALL 包含旧服务端名称解析、查询评分、父目录增强、Codex 聚类与兜底、单项／目录重识别及真实季集策略。旧识别测试与典型 case MUST 迁入当前可执行验证，并维护来源及对应覆盖；不能将仅记录旧方法名、旧构建通过或未运行的测试视为迁移完成。已知安全缺陷继续按桌面约束验证。

#### Scenario: 旧规则回归
- **WHEN** 验证当前识别实现
- **THEN** 固定规则夹具、Codex 原回归、旧 Java 对应当前测试及累计集号、哈希副本、别名和跨季 case 均有可执行入口与明确结果
