# 本地目录接入增量规格

## MODIFIED Requirements

### Requirement: 本地目录来源单向同步

本地来源 SHALL 配置输入目录、同步 target、过滤和周期，采用与网盘来源一致的单向同步规则及成功历史，不依赖网盘登录。来源 MUST 不配置媒体类型或整理目标。文件进入同步前 SHALL 核对就绪证据；未知客户端行为要求人工确认，不把稳定大小当作完整下载证明。

#### Scenario: 本地文件同步
- **WHEN** 用户配置有效本地输入和独立同步 target 并确认预览
- **THEN** 完整文件复制到 target 并记录同步结果，输入文件保留，不直接执行媒体识别或写媒体库

#### Scenario: 本地副本删除后再次同步
- **WHEN** 文件已成功同步，用户删除 target 中副本后重新扫描
- **THEN** 同一源版本不再次传输，遵循受管云端下载规格中的成功历史与显式重新同步规则

#### Scenario: 网盘服务不可用
- **WHEN** 尚未连接网盘或 OpenList 不可用
- **THEN** 有效的本地同步仍可执行，不要求网盘凭据

#### Scenario: 历史本地整理配置迁移
- **WHEN** 应用打开含有旧版直接整理来源、且格式不被当前构建支持的数据目录
- **THEN** 遵循桌面数据生命周期规格拒绝业务启动并保留原数据和媒体，不自动转换独立识别规则、不搬动文件、不插入额外同步；用户使用新数据目录时须重新配置并预览确认
