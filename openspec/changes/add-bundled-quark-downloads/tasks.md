# 实施任务

业务主线依赖顺序：1 → 2 → 3/4 → 5 → 6 → 7。这里的斜线表示无严格先后依赖，不要求多代理执行；8.x 可替换性验证和 9.x 打包验收按对应功能阶段接入，具体接续顺序见下文。实施状态以勾选和证据为准；完成须同时满足对应验证，规划文件生成不计为功能完成。

当前平台范围按用户最新决定收敛为一个 macOS 客户端：优先 Apple Silicon 的真实功能闭环，Intel 复用同一产品并单独核验架构及安装包。已有三目标资产和验收记录保留；Windows 等其他平台只保留扩展性与兼容，不再要求新功能同步验收，也不阻塞 Mac 内测。下列已完成项保留原始验证口径，不因范围调整改写历史结果或新增完成项。

接续优先级：4.1–4.3 → 5.x → 8.1，并随一次性下载准备 9.1/9.4 的 Mac 内测包；之后推进 6.x、7.x、8.2/8.3 及其余 Mac 升级/发行工作。9.x 可先做对应阶段的验证，只有满足整项要求才勾选。9.3 正式签名/公证仍因缺少配置保持未完成，不阻塞 Mac 功能开发；7.3 仍依赖前案真实整理/交付。
