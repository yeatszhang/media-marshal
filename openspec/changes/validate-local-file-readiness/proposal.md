夸克官方客户端目前仅有正常下载／完成改名观察，暂停、断网、预分配和同名重下等证据不足，不能把稳定窗口当成完整下载证明。

夸克 macOS 官方客户端行为矩阵、10 秒复查与 120 秒窗口、健康反馈及未知行为人工降级；不扩展其他网盘或平台。

官方客户端观察可独立开展；最终健康／自动策略页面接线依赖 add-independent-recognition-mapping，来源与识别采用新的职责归属。
