# 实施任务

按复选框记录实际完成状态。目标为 npm workspaces monorepo 中采用 `@yeatz/app-framework` 的独立 Electron + React 客户端；一期所需 Java 业务迁入 TypeScript Utility Process，三进程分别使用 Application 与静态模块。旧 Web/Java/Docker 工程保留作参考，不作为桌面运行依赖或同步交付门槛。每项记录对应验证，未满足完整验收的项目保留未勾选。

当前只交付一个 Mac 客户端，优先完成 Apple Silicon 的真实功能和可用内测包，Intel 复用同一产品并单独记录架构与安装验证。Windows 等其他平台保留平台策略、资源清单和兼容测试，新功能不要求同步验收；已有三目标记录不删除，也不因本次收敛新增完成项。Mac 正式签名/公证因暂无配置保持未完成，不阻塞功能开发。

第一里程碑仅先走通维护者自己的老用户链路，使用已有本机 Emby、实际下载来源和指定媒体目录；地址与路径取自本机配置或明确选择，不预填为产品默认值。

1. 优先推进 6.1、6.6、7.2：复用已有连接，只绑定本次所需的媒体类型和目录，验证身份、库类型、路径及读取/刷新权限，不重装 Emby 或初始化媒体库。
2. 接通本次链路所需的识别确认、5.1–5.5 整理复制和 6.2–6.5 交付；与内置下载变更协同验证下载完成、接入意图及目标绑定。下载侧 7.2 已有候选接入完成记录，真实 Emby 闭环仍须按其 7.3 验收，不能据此提前标记收录完成。
3. 优先完成 9.4 本机真实资源验收，证明下载、整理到指定路径、刷新和收录可用，并验证重复操作、重启恢复与仅重试交付。
4. 再补齐通用来源适配、批量修正、其他架构和 9.1/9.2 完整验收矩阵；新用户 Emby 安装与媒体库初始化后续规划，不作为第一里程碑前置。第一里程碑完成不等于整个 change 完成，原任务与安全要求继续保留。
