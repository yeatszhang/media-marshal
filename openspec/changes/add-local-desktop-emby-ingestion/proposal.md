# 统一来源的桌面下载、整理与 Emby 入库提案

## 为什么

已有 Emby 的用户需要在一个 Mac 应用中完成网盘或本地目录接入、可靠下载、媒体整理和收录核对。账号、目录订阅与本地来源分散配置，会让用户反复填写同一链路，并混淆网盘目录、本地下载目录和媒体库目标；本变更将网盘账号、来源单向同步、识别映射拆成独立配置与执行模块，通过同步成果串联全过程。

本变更整合原 `add-bundled-quark-downloads`，保留 `add-local-desktop-emby-ingestion` 作为下载、整理与交付的统一主变更。两部分共享来源身份、目录授权、任务持久化和恢复约束，按能力分组实施及验收，不再互相等待另一份变更。现有实现状态与历史证据继续保留，合并规划不表示功能已全部完成。

## 变更内容

- 本次网盘产品能力仅支持夸克。百度、阿里等其他网盘的账号接入、专属来源引导、下载完成规则和验收留待后续需求；保留 Provider／Engine 契约、能力声明与静态注册扩展边界，不预建其他网盘实现或入口。通用本地目录整理继续保留，不据此宣称支持其文件来源对应的网盘。
- 「云端网盘」页只负责连接账号、查看状态、重新授权和解除连接。夸克默认使用独立网页登录窗口扫码，Main 获取登录态并验证；手动 Cookie 作为备用，凭据不通过读取接口回显，不宣称官方 OAuth 接入。
- 「来源配置」统一选择「网盘」或「本地目录」。网盘来源配置账号和远端范围，本地来源配置输入目录；两者均配置单向同步 target、过滤条件与周期。来源不持有识别或媒体库目标配置。设置页统一配置默认本地下载目录，来源可显式选择其他同步 target。本次仅支持夸克网盘，普通本地来源保留夸克客户端标签和自定义目录；标签不代表已连接云端账号。
- **BREAKING（导航与配置入口）：** 来源不再持有 organization，旧配置迁移到独立识别规则；新增本地来源执行输入到同步 target 的复制，旧本地直整配置保留原路径并迁为直接识别。移除独立目录订阅配置页，将持续订阅变为网盘来源的周期扫描设置；远端浏览及下载目录选择移入来源表单。保留一次性文件／目录下载、增量、暂停、取消和重试能力，任务页分别展示下载、整理与 Emby 交付状态。
- 独立「识别与映射」页配置输入目录、识别规则及按电影／剧集类型划分的多个 target，并执行可查询、可恢复的映射任务；默认输入为本地下载目录。配置 Emby 后，根据路径自动识别目标所属媒体库；不同路径命名空间使用显式路径转换，歧义待确认。
- 来源同步规则以 rclone copy 及过滤语义为基准，保留不自动覆盖、不镜像删除的产品约束。已成功同步的同一源文件版本，即使本地副本被删除也不自动重下；持久化完成历史，只有显式重新同步或可靠的新版本才产生新需求。
- 沿用 Electron、React、TypeScript、npm workspaces、electron-vite、electron-builder 和 `@yeatz/app-framework`。Main、媒体 Core、Renderer 与 SidecarHost 分别管理自身 Application；Core 独占业务 SQLite，Renderer 只调用受限业务 IPC。
- 随包提供 OpenList、Rclone、Guardian 和冻结 guessit，用户无需安装 Docker、JRE、Node.js 或 Python。OpenList 提供网盘访问，Rclone 按批次传输；应用持有扫描、增量、调度、核对及恢复事实，Provider／Engine 保持可替换。
- 下载先写受管暂存区，核验后不覆盖提交，再幂等交接识别与整理。电影和普通剧集沿用预览、低置信度确认、模板及 COPY 规则，保留来源文件；下载目录与整理后的媒体库保持分离。
- 当前优先复用已有 Emby、指定电影／剧集目录和连接配置；文件整理、刷新、等待收录及已收录独立持久化，Emby 离线仅重试交付。Emby 自动安装、启动及首次初始化迁入独立后续变更，本次仅接入已有服务器。
- 只交付一个 macOS 客户端，Apple Silicon 优先，Intel 按实际验证提供同产品安装包；非 macOS 客户端适配、兼容补齐与发行迁入独立后续变更，本次不承担其新增实现或验收。未签名内测与正式签名发行分别验收，缺少签名配置不阻塞功能开发。
- 保留旧 Java／Vue／Docker 工程作为迁移参考及独立入口，不运行旧媒体 HTTP/WS 服务、不导入旧服务端数据库。受管网盘所需的授权回环服务与私有凭据副本有独立权限及导出边界。

## 能力

### 新增能力

- `desktop-runtime`：应用框架、进程隔离、受限 IPC、生命周期、React 状态、配置与诊断。
- `cloud-drive-access`：账号管理、来源内远端目录选择、接入能力、授权恢复及 Provider 替换。
- `managed-cloud-downloads`：网盘来源映射、周期扫描、增量下载、恢复、文件提交及整理交接。
- `bundled-transfer-runtime`：随包组件、授权回环服务、凭据隔离、Guardian 监管与组件升级。
- `local-folder-ingestion`：本地来源单向同步、独立识别规则与多目标映射、受管完成项接入、就绪检查、COPY、修正及恢复。
- `emby-delivery`：已有服务器与指定媒体库接入、刷新、收录核对及独立重试。
- `desktop-distribution`：自包含 Mac 安装、依赖追踪、签名、手动升级与数据保留。

### 修改能力

无。当前主规格为空；七份增量规格共同定义本次客户端交付。原云端三份规格迁入本变更，能力标识保持不变，不在主规格中伪造已归档能力。

## 影响

- 影响 `apps/desktop`、`packages/contracts`、`packages/media-core`、`tools/desktop-parser` 和 `tools/desktop-sidecars` 的来源契约、页面、持久化关联、调度与发行验证。沿用锁定框架依赖和公开入口，不引入第二套 DI 或全局前端任务存储。
- 通过有序迁移建立统一来源身份，关联现有本地来源、订阅、下载需求与整理绑定；保留账号、任务 ID、配置版本、暂停状态、执行历史和媒体文件。普通本地来源不自动转换成网盘来源，历史一次性下载不自动变成持续订阅。
- 完成来源入口与迁移改造后，沿用原有下载、文件、识别和交付状态机；识别规则的输入重叠与目标匹配歧义须在预览／执行前解释并阻断，不允许新界面重复启动后台任务。
- 正式发行继续验证原生 SQLite ABI、冻结解析器、网盘组件、架构筛选、许可与源码材料。安装包不带个人配置，卸载不删除数据或媒体；手动升级使用一致性备份，回退不能被解释为撤销文件操作。
- 不实现远端写入、双向同步、镜像删除、下载加速、通用插件市场、NAS/Web 产品、旧库导入、音乐／ISO／蓝光或非 COPY 入库。未完成文件可能重新下载，不承诺跨进程字节级续传。
- 桌面与整理核心免费；官方 API、托管通知、支付和商店发行独立规划，见[商业与付费策略](../../../docs/product/business-and-operations.md)。

## 当前交付顺序

先完成账号、来源同步、识别映射职责拆分与配置迁移，再使用维护者自己的 Mac、已有 Emby 与指定媒体目录完成真实链路：账号连接 → 来源同步及下载预览 → 下载校验提交 → 识别确认和整理预览 → COPY → 刷新与收录核对。只下载时无需先配置 TMDB、媒体库或 Emby；在独立识别页启用映射和交付时再验证相应配置。

实际地址、库标识与绝对路径取自本机保存配置或用户明确选择，不写入公开规划或产品默认值。新用户的 Emby 安装初始化已移至独立 change，不属于本次全部里程碑。其他网盘由后续独立需求确定范围，不作为本次验收或归档前置。之后补齐夸克本地来源与通用目录、批量修正、其他 Mac 架构及完整故障矩阵；公开发行单独满足签名、公证和安装态门槛。任务合并映射、未完成项与历史验收口径见 [tasks.md](tasks.md)。
