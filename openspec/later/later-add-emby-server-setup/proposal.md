# Emby 自动安装与首次初始化提案

## 为什么

当前主变更只连接已有 Emby，尚未安装或初始化服务器的新用户无法直接完成入库。将自动安装、启动及首次设置独立规划，避免阻塞现有服务器用户的下载和整理闭环。

本变更由 [add-local-desktop-emby-ingestion](../archive/2026-10-27-add-local-desktop-emby-ingestion/proposal.md) 于 2026-10-25 拆出，状态为后续待实施；不属于主变更的验收或归档前置。本次只迁移规划，不实施功能。

## 变更内容

- 在用户选择新建服务器后，协助自动安装与启动本机 Emby，并完成首次账号、媒体目录及媒体库初始化。
- 检测已有安装与初始化状态，提供直接复用入口；失败、取消及重启可恢复，不覆盖已有服务器配置或媒体。
- 初始化成功后转交现有连接、目标绑定与独立交付流水线，不再维护另一套入库逻辑。
- 首次实施以已支持的 macOS 为范围；其他客户端需先完成独立平台变更。不包含远程 NAS、容器部署、服务器升级管理或媒体搬迁。

## 能力

### 新增能力

- `emby-server-setup`：本机 Emby 安装、启动、首次初始化及安全接入已有交付链路。

### 修改能力

无。当前主规格为空；本增量只定义后续扩展，不复制主变更的七份基础规格。实施前按当时已归档主规格复核能力边界及与本扩展有关的范围限制。

## 影响

新增桌面安装向导、受限宿主动作、初始化记录及 Emby 首次设置适配；现有 packages/media-core/src/infrastructure/emby.ts 只提供连接、查询与刷新，不能视为已有安装能力。

依赖主变更对应的运行、来源与交付基线。其他后续变更可独立排期，不隐含同时实施。原任务完成状态不迁移为本变更的完成证据。
